# Library Management System

A console-based Library Management System developed using C++ as a university project.

## Project Objective

The objective of this project is to manage library books, members, book issues, returns, and borrowing records through a simple console application.

## Planned Features

* Add, view, search, update, and delete books
* Register and manage library members
* Issue and return books
* View available and issued books
* Store issue and return dates
* Calculate late return fines
* View member borrowing history
* Display a library summary
* Save and load records using file handling

## C++ Concepts

* Variables and data types
* Conditional statements
* Loops and switch statements
* Functions
* Classes and objects
* Vectors
* Searching and sorting
* File handling
